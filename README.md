# TraceDeck Privacy Site

Standalone, dependency-free privacy policy site for TraceDeck. It is intentionally
kept outside the browser-extension package.

## Publish with GitHub Pages

1. Create a public repository named `tracedeck-privacy` under the `kiyansh-k`
   account.
2. Copy the contents of this directory to the repository root.
3. In **Settings → Pages**, publish from the repository's default branch and
   `/ (root)`.
4. Confirm the site is available at
   `https://kiyansh-k.github.io/tracedeck-privacy/`.
5. Use that URL in the Chrome Web Store privacy policy field.

The page uses no external scripts, fonts, analytics, cookies, or network assets.
Its light and dark appearance follows the visitor's operating-system preference.
